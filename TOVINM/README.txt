TOVINM GitHub Pages 업로드 방법

1. GitHub 저장소 루트에서 Add file → Upload files
2. 이 압축파일을 풀어 나온 TOVINM 폴더 안의 파일들을,
   저장소의 TOVINM 폴더에 그대로 업로드합니다.

구조:
TOVINM/
├─ index.html
├─ styles.css
├─ script.js
└─ assets/
   └─ 이미지 파일들

접속 주소:
https://soldidi9548.github.io/TOVINM/

중요:
- TOVINM.html 한 파일로 올리는 방식이 아니라 TOVINM 폴더 전체를 올려야 합니다.
- 폴더 안의 index.html 이름을 바꾸면 위 주소로 접속되지 않습니다.
