GitHub Pages 업로드 방법

1. 이 ZIP의 내용물을 전부 압축 해제합니다.
2. GitHub 저장소의 최상위(root)에 index.html, style.css, script.js, assets 폴더를 그대로 업로드합니다.
3. Settings → Pages → Deploy from a branch → main / root 선택 후 저장합니다.
